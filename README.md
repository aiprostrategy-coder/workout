# Тренировки

Учёт повторений за день: подтягивания, отжимания, брусья, приседания, пресс,
планка (секундомер) и вес тела. Одна страница, без сборки и зависимостей.
Данные лежат в браузере телефона, наружу не уходят.

## Как считаются подходы

Нажатия одного упражнения, идущие друг за другом с паузой меньше 3 секунд,
складываются в один подход. Окно скользящее: отсчёт перезапускается с каждого
нажатия, поэтому `+10 → +1 → +1` даёт подход 12, даже если между нажатиями
по 2,5 секунды. После паузы начинается новый подход.

«Отменить» снимает одно последнее нажатие, а не весь подход, и работает только
в пределах сегодняшнего дня.

Серия — дни подряд, в которых есть хотя бы одно повторение. Вес тела тренировкой
не считается. Если сегодня ещё пусто, серия показывает вчерашнюю, а не ноль.

## Офлайн

Service worker регистрируется и берёт страницу под контроль, в кэше `workout-v1`
лежат все пять файлов с полными телами (проверено на опубликованном адресе).
Стратегия «кэш-первым», поэтому запуск без сети не ходит в интернет вовсе.

Непроверенным остаётся поведение конкретно вашего телефона — его проверяете вы:
загрузите страницу, включите режим полёта, запустите с главного экрана. Если не
откроется, в **DevTools → Console** при отказе регистрации пишется строка
«Офлайн-режим не включился» с причиной.

## Бэкап

«Экспорт» скачивает весь архив одним JSON-файлом, «Импорт» возвращает его обратно,
заменяя текущие данные. Очистка данных браузера стирает записи — другого
автоматического бэкапа нет и не будет без сервера.

## Разработка

```bash
node serve.mjs            # http://localhost:8123 — нужен только для service worker
```

Тесты логики — `test.html` в браузере, без установки чего-либо. Зелёный заголовок
«ВСЕ N ПРОЙДЕНЫ» — единственный критерий.

| Файл | Что внутри |
|---|---|
| `core.js` | вся логика: подходы, отмена, серия, недельные итоги, вес. Без DOM |
| `index.html` | интерфейс и хранение |
| `test.html` | тесты `core.js` |
| `sw.js` | офлайн-кэш |
| `serve.mjs` | локальный сервер, в публикации не участвует |

При правке `index.html`, `core.js` или `icon.svg` поднимите номер кэша в `sw.js`
(`const CACHE = 'workout-v2'`), иначе телефоны останутся на старой версии.
